The things worth sharing are usually the ones you built for yourself first.

I've been calling them byproducts. Tools, templates, and patterns that emerged from building something else. Not because I set out to make them. A hook built to enforce my own habits. A template for my own writing process.

A few from the last week:

**[claude-code-hooks](https://github.com/jordanlyall/claude-code-hooks)**: hooks that make Claude Code sessions more accountable. Promise Checker, Session Artifact Check, Key Light integration, auto git backup.

**[writing-voice-skill](https://github.com/jordanlyall/writing-voice-skill)**: a template for teaching Claude to write in your voice. Fill in your patterns, anti-patterns, and context profiles.

The ones that feel useful to others are always the ones I built to solve a specific, annoying problem. Not "I should build a useful tool." Just: this is broken, here's the fix.
