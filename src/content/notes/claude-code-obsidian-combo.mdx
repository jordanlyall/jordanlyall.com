Killer app for me is Claude Code + Obsidian vault. Super powerful combo.

Been shipping repos as byproducts of this setup. Latest one: tasks auto-sync to Apple Reminders, bidirectional. Complete something on your Watch or via Siri, it syncs back in today's note.

Hooks fire automatically on every file write and session start. No prompts, just hooks.

Didn't set out to build it on purpose. It fell out of the iteration and improvements.
